# Архитектура проекта

## Общая идея

Проект сделан как простое одностраничное приложение без сборщика и фреймворка.

Все экраны находятся в `index.html`, стили - в `styles.css`, поведение разделено на несколько JavaScript-файлов.

Проект можно открывать как обычный HTML-файл в браузере.

## Структура файлов

### `index.html`

Главная HTML-разметка приложения.

Содержит три экрана:

- заставка;
- экран выбора игры;
- игровой экран Memory.

Также подключает CSS и JavaScript-файлы в нужном порядке.

### `styles.css`

Все визуальные стили проекта:

- фон;
- заставка;
- экран выбора игры;
- игровой экран;
- карточки Memory;
- адаптация под размер экрана;
- анимации.

Пока CSS остается в одном файле, потому что визуальный стиль общий и проект небольшой.

### `data.js`

Данные проекта:

- список шахматистов;
- пути к фотографиям;
- настройки сложности.

Этот файл не управляет интерфейсом и не содержит игровой логики.

### `screens.js`

Отвечает за переключение экранов.

Главная функция:

- `showScreen(screen)` - показывает выбранный экран и скрывает остальные.

### `setup.js`

Отвечает за экран выбора игры.

Содержит:

- получение выбранного типа карточек;
- получение выбранного режима;
- получение выбранной сложности;
- переключение активного состояния кнопок.

### `game-preview.js`

Отвечает за текущий визуальный прототип игрового экрана.

Содержит:

- создание предварительной колоды;
- отрисовку карточек;
- отображение верхней панели результата;
- различия между режимами `Один игрок` и `Два игрока`.

Позже часть логики из этого файла можно перенести в отдельные файлы настоящей игры.

### `script.js`

Точка входа приложения.

Содержит:

- запуск заставки;
- построение шахматной доски на первом экране;
- привязку кнопок;
- запуск отрисовки игрового экрана.

Этот файл связывает остальные части проекта, но не должен превращаться в место для всей игровой логики.

## Поток экранов

1. Игрок видит заставку.
2. Нажимает `СТАРТ`.
3. Открывается экран выбора игры.
4. Игрок выбирает:
   - тип карточек;
   - режим;
   - сложность.
5. Нажимает `НАЧАТЬ ИГРУ`.
6. Открывается игровой экран.

## Варианты игры

Сейчас поддерживаются два типа карточек:

- `Фото - фото`;
- `Фото - фамилия`.

И два режима:

- `Один игрок`;
- `Два игрока`.

## Правила развития проекта

### Данные отдельно от логики

Новые шахматисты, фотографии и настройки сложности добавляются в `data.js`.

### Переключение экранов отдельно

Если появятся новые экраны, их переключение должно проходить через `screens.js`.

### Логика выбора отдельно

Все изменения, связанные с выбором режима, сложности или типа игры, лучше добавлять в `setup.js`.

### Игровая логика отдельно

Когда появится настоящая механика Memory, ее лучше вынести из `game-preview.js` в отдельные файлы.

Возможные будущие файлы:

- `deck.js` - создание колоды карточек;
- `game-state.js` - состояние партии;
- `game-rules.js` - проверка пар и ходов;
- `game-view.js` - отрисовка игрового поля и счета.

## Важное замечание по JavaScript

Проект использует обычные `<script>`-файлы без `type="module"`.

Поэтому файлы изолируются внутри самовызывающихся функций и передают наружу только нужные объекты через `window.ChessLegends...`.

Это позволяет открывать проект как обычный HTML-файл и снижает риск конфликтов имен между JavaScript-файлами.

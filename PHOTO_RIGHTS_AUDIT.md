# Аудит прав на фотографии

Статус: выполнено для текущего набора игры.

## Что сделано

1. Для каждого шахматиста выбран конкретный исходный файл Wikimedia Commons.
2. Старый неподтвержденный набор из `assets/photos/` удален.
3. Новый набор скачан в `assets/photos/commons/`.
4. `data/data.js` переключен на новые файлы.
5. Добавлен `PHOTO_CREDITS.md` со ссылками на Commons, авторами/источниками и лицензиями.
6. В приложении добавлена ссылка `Авторы фото`, ведущая на `PHOTO_CREDITS.md`.

## Проверенный набор

Все текущие игровые изображения лежат в:

```text
assets/photos/commons/
```

В игре используются только пути вида:

```text
assets/photos/commons/01-steinitz.jpg
...
assets/photos/commons/32-nepomniachtchi.jpg
```

## Важные условия

- Public domain и CC0 файлы можно использовать свободно, но источник оставлен в credits для прозрачности.
- CC BY файлы требуют указать автора, источник, лицензию и изменения.
- CC BY-SA файлы требуют то же самое; измененные версии самих фотографий должны распространяться на совместимых ShareAlike-условиях.
- Код игры не обязан автоматически становиться CC BY-SA из-за использования CC BY-SA изображений, но сами изображения и их локальные resized/thumbnail версии должны соблюдать условия соответствующих лицензий.

## Перед публикацией

Перед релизом убедиться, что `PHOTO_CREDITS.md` публикуется вместе с сайтом и доступен по ссылке `Авторы фото`.

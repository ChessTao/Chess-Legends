# Ближайший план бесплатного онлайн-размещения

Выбранный путь для первого закрытого теста:

1. Входная страница игры живет на `aveskulov.com` в скрытом разделе без ссылки с основного сайта.
2. В `index.html` стоит `noindex`, чтобы страницу не индексировали поисковики.
3. Рабочие данные переносим из `.runtime/*.json` в PostgreSQL.
4. Локально используем Docker Compose:

   ```text
   app + postgres
   ```

5. Для бесплатного публичного запуска можно разделить:

   ```text
   aveskulov.com - скрытая страница/точка входа
   Node/Docker app - бесплатный web service
   PostgreSQL - бесплатный managed Postgres, например Neon Free
   ```

Render больше не является обязательным. Если используем Render Free только для Node-приложения, persistent disk не нужен: данные должны лежать в PostgreSQL. Render Free Postgres для живых данных не выбираем, потому что бесплатная база ограничена по времени.

## Следующий технический шаг

Слой хранения в сервере уже вынесен в `server-storage.js`:

- текущий JSON-режим остался рабочим fallback для локальной разработки;
- `server.js` читает и пишет профили, сессии, комнаты и лог ошибок через storage-интерфейс;
- `npm.cmd run check` проходит;
- `npm.cmd run runtime-restart-check` проходит.

Следующий шаг:

PostgreSQL-реализация storage-интерфейса добавлена в совместимом режиме:

- при наличии `DATABASE_URL` сервер выбирает PostgreSQL;
- данные пока хранятся как JSONB-снимки в таблице `app_store`;
- серверные ошибки пишутся в таблицу `server_errors`;
- без `DATABASE_URL` остается JSON fallback.
- локально проверено через Docker Postgres: `runtime-restart-check` и `online-smoke` проходят с `DATABASE_URL`.

Следующий шаг:

1. Решить, оставляем ли переходный JSONB-формат для первого закрытого теста.
2. Если да, готовить публичный PostgreSQL на бесплатном сервисе и деплой Node-приложения.
3. Если нет, следующим этапом разложить данные по нормальным таблицам: `profiles`, `sessions`, `online_rooms`, `matches`.
4. После каждого шага прогонять `npm.cmd run check`, `npm.cmd run runtime-restart-check` и `npm.cmd run online-smoke`.

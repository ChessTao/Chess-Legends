# Памятка: вход с паролями

Чтобы регистрация и вход с паролем работали правильно, открывайте проект через локальный сервер.

## Правильный запуск

В терминале из папки проекта:

```powershell
npm.cmd start
```

После запуска откройте в браузере:

```text
http://127.0.0.1:4173/
```

## Почему нельзя открывать `index.html` напрямую

Если открыть `index.html` двойным кликом или через `file://`, сама игра может частично загрузиться, но серверные запросы для профилей не будут доступны:

- `/api/register` - регистрация профиля с паролем;
- `/api/login` - вход по имени и паролю;
- `/api/profiles` - загрузка профилей.

Из-за этого пароль может не сохраниться, вход может не сработать, а игра покажет ошибку про сервер профилей.

## Быстрая проверка

Правильный адрес в строке браузера начинается так:

```text
http://127.0.0.1:4173/
```

Неправильный вариант выглядит примерно так:

```text
file:///D:/.../index.html
```

## Если PowerShell ругается на `npm`

На Windows лучше использовать:

```powershell
npm.cmd start
```

А не:

```powershell
npm start
```

Так запуск не упирается в политику выполнения `npm.ps1`.

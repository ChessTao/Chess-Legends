# Шахматные Легенды

Одностраничная игра Memory про шахматистов. Проект работает без сборщика: HTML, CSS, JS и локальные изображения лежат в репозитории и могут отдаваться любым статическим хостингом.

## Запуск локально

```bash
npm start
```

По умолчанию сервер открывается на `http://127.0.0.1:4173/`.

## Проверка перед публикацией

```bash
npm run check
```

Команда проверяет синтаксис серверного файла и всех JavaScript-файлов приложения.

## Публикация

Самый простой вариант - загрузить корень проекта на статический хостинг: Netlify, Vercel, GitHub Pages или любой сервер, который отдает `index.html`, папки `assets/`, `data/`, `src/` и `styles/`.

Если используется Node-сервер из репозитория:

```bash
HOST=0.0.0.0 PORT=4173 NODE_ENV=production npm start
```

На Windows PowerShell:

```powershell
$env:HOST="0.0.0.0"; $env:PORT="4173"; $env:NODE_ENV="production"; npm start
```

## Данные

Профили, рекорды и настройки хранятся в `localStorage` браузера пользователя. Серверная база данных не нужна.

## Фотографии

Игровые фотографии лежат в `assets/photos/commons/` и взяты с Wikimedia Commons. Авторы, источники и лицензии перечислены в `PHOTO_CREDITS.md`; этот файл нужно публиковать вместе с сайтом.

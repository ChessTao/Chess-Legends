# Правила игры Memory

## Основная идея

Memory - это игра на запоминание карточек. Игрок открывает две карточки за ход и старается найти пару.

В игре есть два варианта пар:

1. **Фото - фото**: нужно найти две одинаковые фотографии шахматиста.
2. **Фото - фамилия**: нужно найти фотографию шахматиста и карточку с его фамилией.

Перед началом игрок выбирает вариант игры и режим прохождения.

## Варианты игры

### Фото - фото

На поле лежат карточки с фотографиями шахматистов.

Каждая фотография встречается два раза.

Пара считается найденной, если игрок открыл две одинаковые фотографии.

Пример пары:

- фото Каспарова;
- такое же фото Каспарова.

### Фото - фамилия

На поле лежат карточки двух типов:

- фотографии шахматистов;
- фамилии шахматистов.

Пара считается найденной, если игрок открыл фотографию шахматиста и соответствующую фамилию.

Пример пары:

- фото Каспарова;
- карточка `Каспаров`.

## Подготовка

1. Игрок выбирает вариант игры: `Фото - фото` или `Фото - фамилия`.
2. Игрок выбирает режим: `Один игрок` или `Два игрока`.
3. На поле выкладывается четное количество карточек рубашкой вверх.
4. Все карточки перемешиваются перед началом игры.
5. Перед первым ходом игроки не видят содержимое карточек.

## Общие правила хода

1. Игрок открывает первую карточку.
2. Затем игрок открывает вторую карточку.
3. Если карточки образуют пару, они остаются открытыми.
4. Если карточки не образуют пару, они закрываются обратно после короткой паузы.
5. За один ход можно открыть только две карточки.

## Режим одного игрока

В одиночном режиме игрок играет на скорость.

Цель - найти все пары как можно быстрее.

### Подсчет результата

В одиночном режиме учитывается:

- время прохождения;
- количество ходов.

Главный результат - время.

Чем быстрее игрок нашел все пары, тем лучше результат.

### Завершение игры

Игра заканчивается, когда найдены все пары.

После завершения показывается:

- итоговое время;
- количество ходов;
- кнопка повторной игры.

## Режим двух игроков

В режиме на двоих игроки соревнуются по количеству найденных пар.

Цель - найти больше пар, чем соперник.

### Начало игры

1. Игроки выбирают имена или используют названия `Игрок 1` и `Игрок 2`.
2. Первый ход делает `Игрок 1`.
3. На экране показывается, чей сейчас ход.
4. У каждого игрока есть счет найденных пар.

### Правила хода

1. Игрок открывает две карточки.
2. Если карточки образуют пару, игрок получает 1 очко.
3. Найденная пара остается открытой на поле.
4. После найденной пары этот же игрок ходит еще раз.
5. Если карточки не образуют пару, они закрываются обратно.
6. После ошибки ход переходит ко второму игроку.

### Подсчет результата

В режиме на двоих учитывается:

- количество пар у `Игрока 1`;
- количество пар у `Игрока 2`.

Главный результат - количество найденных пар.

### Победа

Игра заканчивается, когда найдены все пары.

Побеждает игрок, который нашел больше пар.

Если оба игрока нашли одинаковое количество пар, объявляется ничья.

После завершения показывается:

- счет `Игрока 1`;
- счет `Игрока 2`;
- победитель или ничья;
- общее количество ходов;
- кнопка повторной игры.

## Сложность

### Начинающий

- поле 4 x 4;
- 16 карточек;
- 8 пар карточек;
- подходит для первого знакомства.

### КМС

- поле 8 x 4;
- 32 карточки;
- 16 пар карточек;
- подходит для обычной игры.

### Мастер

- поле 12 x 4;
- 48 карточек;
- 24 пары карточек;
- подходит для опытных игроков.

### Гроссмейстер

- поле 12 x 5 + 4 карточки снизу;
- 64 карточки;
- 32 пары карточек;
- подходит для максимальной сложности.

## Ограничения

- Нельзя открыть больше двух карточек за один ход.
- Нельзя выбрать одну и ту же карточку два раза за один ход.
- Нельзя повторно выбирать уже найденную пару.
- Пока две несовпавшие карточки закрываются обратно, новые карточки временно нельзя открывать.

# План развития проекта

Цель проекта - превратить текущую Memory-игру "Шахматные Легенды" в онлайн-игру для публикации на сайте, с профилями игроков, рекордами, рейтингами и английской версией.

## Этап 1. Подготовить игру к публикации

Цель: текущая игра должна стабильно открываться на сайте.

- Привести структуру проекта к аккуратному виду:
  - `index.html`
  - `src/` для JavaScript
  - `styles/` для CSS
  - `assets/photos/` для фотографий
  - `data/` для данных шахматистов
- Убрать привязку к локальной структуре вроде `Фотографии/...`.
- Заменить локальные пути на веб-пути.
- Проверить игру через локальный сервер, а не только открытием HTML-файла.
- Подготовить базовую сборку для загрузки на сайт.

Результат: игру можно залить на сайт как обычную веб-страницу.

## Этап 2. Английская версия

Цель: добавить переключатель языка RU / EN.

- Вынести весь текст интерфейса из HTML и JS в словари:
  - `ru`
  - `en`
- Добавить переключатель языка.
- Перевести:
  - кнопки;
  - настройки;
  - результат игры;
  - названия режимов;
  - подписи счета;
  - фамилии шахматистов, если нужно: `Каспаров` / `Kasparov`.
- Сохранять выбранный язык в `localStorage`.

Результат: одна игра, два языка.

## Этап 3. Локальные профили игроков

Цель: сначала сделать профили без сервера, чтобы быстро проверить механику.

Профиль игрока:

- имя;
- флаг или страна;
- шахматный рейтинг;
- игровой рейтинг Memory;
- рекорд по времени;
- рекорд по ходам;
- количество сыгранных партий;
- победы в режиме двух игроков.

На этом этапе данные можно хранить в `localStorage`.

Результат: игрок создает профиль, играет, рекорды сохраняются на его устройстве.

## Этап 4. Онлайн-версия с сервером

Цель: профили и рекорды доступны с разных устройств.

Минимальная архитектура:

- frontend: текущая игра;
- backend/API: авторизация, профили, рекорды;
- database: игроки, результаты, рейтинги;
- hosting: сайт или отдельный поддомен.

Минимальные сущности:

```text
User
- id
- name
- country
- flag
- chessRating
- gameRating
- createdAt

GameResult
- id
- userId
- mode
- cardType
- difficulty
- timeSeconds
- moves
- pairs
- score
- createdAt
```

Результат: реальные онлайн-профили и сохранение результатов.

## Этап 5. Таблицы лидеров

Цель: добавить соревновательность.

Отдельные рейтинги:

- лучший результат по времени;
- лучший результат по ходам;
- рейтинг по сложности;
- рейтинг по режиму;
- общий игровой рейтинг;
- рекорды по странам.

Фильтры:

- день;
- неделя;
- месяц;
- все время;
- сложность;
- язык или регион.

Результат: игрокам есть зачем возвращаться.

## Этап 6. Онлайн-аккаунты

Цель: нормальная система входа.

Варианты:

- простая регистрация по email;
- вход через Google;
- гостевой профиль с возможностью потом привязать аккаунт.

Лучше начать с гостевого профиля с именем и страной, а полноценную авторизацию добавить позже.

Результат: меньше трения на старте, но есть путь к постоянному аккаунту.

## Этап 7. Публикация на сайте

Цель: встроить игру красиво и надежно.

Варианты размещения:

- отдельная страница: `site.com/chess-legends`;
- поддомен: `chess.site.com`;
- iframe внутри существующего сайта;
- полноценный раздел сайта.

Предпочтительный вариант: отдельная страница или поддомен. Для игры это чище: проще стили, адаптивность, SEO и обновления.

## Этап 8. Полировка продукта

После запуска основы:

- адаптивность для телефона;
- экран загрузки;
- обработка ошибок сети;
- красивые флаги;
- аватар или эмблема профиля;
- статистика игрока;
- достижения;
- ежедневный вызов;
- обучающий первый запуск;
- звуки с выключателем;
- режим "соревнование на время".

## Рекомендуемый порядок

1. Стабилизировать текущую офлайн-игру.
2. Подготовить структуру проекта для сайта.
3. Добавить английскую версию.
4. Добавить локальные профили и рекорды.
5. Залить первую версию на сайт.
6. После этого делать сервер, онлайн-профили и таблицы лидеров.

Ближайшая практичная цель: версия 1.0 для сайта без сервера, но уже с RU/EN и локальными профилями. Это даст живую игру на сайте быстро, а онлайн-часть можно развивать поверх нее.

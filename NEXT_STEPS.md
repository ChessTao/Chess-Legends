# Следующие шаги

Текущая стабильная точка: `90a3fe2 add account profile stats`.

## Готово

- Структура проекта разнесена по `src/`, `styles/`, `data/`, `assets/photos/`.
- Игра открывается через локальный сервер.
- Добавлены локальные профили: имя, страна, флаг, гостевой режим, выход из аккаунта.
- Добавлена отдельная страница аккаунта.
- Добавлен слой нескольких локальных профилей:
  - список профилей;
  - активный профиль;
  - миграция старого одиночного профиля;
  - подготовленные функции записи результата одному или двум профилям.
- Добавлен выбор участников матча для режима `Два игрока`:
  - `Игрок 1`;
  - `Игрок 2`;
  - гость;
  - быстрое создание локального профиля;
  - защита от выбора одного профиля за обоих игроков.
- Для одиночной игры сохраняются рекорды по сложностям:
  - количество одиночных партий;
  - лучшее время;
  - лучшие ходы;
  - среднее время за все время;
  - среднее время за последние 5 партий.
- Матчевый рейтинг отделен от одиночной игры.

## Ближайший фокус

1. Довести режим "Два игрока".

   Следующий практический шаг - показать выбранные имена и флаги игроков прямо на игровом экране.

2. Развести интерфейс результата для одиночной игры и матча.

   Одиночная игра должна показывать время, ходы и рекорды. Матч должен показывать счет, победителя, изменение рейтинга и баланс.

3. Обновить страницу аккаунта под матчи.

   Добавить понятную матчевую статистику: общий счет, рейтинг, количество матчей, статистику по уровням сложности.

4. Проверить все комбинации режимов.

   Минимальный набор:
   - Фото - фото / Один игрок;
   - Фото - фамилия / Один игрок;
   - Фото - фото / Два игрока;
   - Фото - фамилия / Два игрока;
   - сложности 16, 32, 48 и 64 карточки.

5. После режима вдвоем снова закоммититься.

   Следующий коммит должен фиксировать именно стабильную матчевую механику.

## План имплементации режима "Два игрока"

### 1. Выбор участников матча

- [x] Добавить экран или секцию перед стартом матча.
- [x] Показывать два слота:
  - `Игрок 1`;
  - `Игрок 2`.
- [x] В каждом слоте дать выбор из локальных профилей.
- [x] Разрешить гостя для одного или обоих слотов.
- [x] Не разрешать выбрать один и тот же локальный профиль сразу в оба слота.
- [x] Добавить быстрое создание нового локального профиля из этого экрана.

Результат: перед матчем приложение знает `matchPlayer1Id` и `matchPlayer2Id`, либо что один из игроков гость.

### 2. Состояние матча

- Добавить в состояние приложения:
  - `matchPlayer1Id`;
  - `matchPlayer2Id`;
  - `matchPlayer1Name`;
  - `matchPlayer2Name`;
  - флаги игроков, если страна выбрана.
- Хранить это в `chessLegendsState`, чтобы случайный переход между экранами не терял выбранных игроков.
- Для одиночной игры продолжать использовать активный профиль.

Результат: одиночная игра и матч перестают конкурировать за один и тот же `activeProfileId`.

### 3. Интерфейс игрового экрана

- В режиме `Два игрока` заменить подписи `Игрок 1` / `Игрок 2` на реальные имена.
- Показывать флаги рядом с именами.
- Ясно выделять текущий ход.
- Оставить счет найденных пар у каждого игрока.
- После найденной пары оставлять ход тому же игроку.
- После ошибки передавать ход другому игроку.

Результат: игрокам понятно, чей ход и какой счет.

### 4. Результат матча

- В финальном окне показывать:
  - победителя по имени;
  - счет матча;
  - ничью, если счет равный;
  - общее количество ходов.
- Для гостя не писать статистику.
- Для локальных профилей писать результат каждому участнику.

Результат: итог матча выглядит как матч, а не как одиночная партия.

### 5. Запись статистики

- Использовать `recordMatchResult(player1Id, player2Id, result)` для двух локальных профилей.
- Если один игрок гость:
  - записывать результат только локальному профилю;
  - корректно определять победа это или поражение для локального игрока.
- Если оба гости:
  - не писать профильную статистику.
- Матч не должен менять одиночную статистику.
- Одиночная игра не должна менять матчевый рейтинг.

Результат: профильная статистика остается разделенной.

### 6. Страница аккаунта

- Добавить блок матчевой статистики по сложностям:
  - матчи;
  - победы;
  - поражения;
  - ничьи;
  - счет.
- Не смешивать этот блок с одиночными рекордами.
- Проверить, что кнопка `Обнулить статистику` очищает только одиночную статистику.

Результат: аккаунт показывает отдельно одиночные результаты и матчевые результаты.

### 7. Проверка сценариев

- Один профиль против гостя.
- Два разных локальных профиля.
- Гость против гостя.
- Попытка выбрать один профиль за обоих игроков.
- Победа Игрока 1.
- Победа Игрока 2.
- Ничья.
- Все сложности.
- Оба типа карточек.

Результат: режим вдвоем стабилен перед коммитом.

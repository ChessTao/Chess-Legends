# Следующие шаги

Текущая стабильная точка: `90a3fe2 add account profile stats`.

## Готово

- Структура проекта разнесена по `src/`, `styles/`, `data/`, `assets/photos/`.
- Игра открывается через локальный сервер.
- Добавлены локальные профили: имя, страна, флаг, гостевой режим, выход из аккаунта.
- Добавлена отдельная страница аккаунта.
- Для одиночной игры сохраняются рекорды по сложностям:
  - количество одиночных партий;
  - лучшее время;
  - лучшие ходы;
  - среднее время за все время;
  - среднее время за последние 5 партий.
- Матчевый рейтинг отделен от одиночной игры.

## Ближайший фокус

1. Довести режим "Два игрока".

   Нужно определить правила матча: как считается победа, поражение, ничья, рейтинг и история матчей по сложностям.

2. Развести интерфейс результата для одиночной игры и матча.

   Одиночная игра должна показывать время, ходы и рекорды. Матч должен показывать счет, победителя, изменение рейтинга и баланс.

3. Обновить страницу аккаунта под матчи.

   Добавить понятную матчевую статистику: общий счет, рейтинг, количество матчей, статистику по уровням сложности.

4. Проверить все комбинации режимов.

   Минимальный набор:
   - Фото - фото / Один игрок;
   - Фото - фамилия / Один игрок;
   - Фото - фото / Два игрока;
   - Фото - фамилия / Два игрока;
   - сложности 16, 32, 48 и 64 карточки.

5. После режима вдвоем снова закоммититься.

   Следующий коммит должен фиксировать именно стабильную матчевую механику.
